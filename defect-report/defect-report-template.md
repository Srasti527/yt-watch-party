## 7. Severity Guide

- **Critical:** A major failure makes the application unusable or causes severe impact.
- **High:** An important feature is broken.
- **Medium:** A feature has a problem, but the application remains usable.
- **Low:** A minor visual or usability issue.

- **P3:** Fix when feasible.
